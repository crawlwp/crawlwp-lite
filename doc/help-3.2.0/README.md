# CrawlWP help articles for free 3.2.0 and Premium 3.4.0

New help articles for the features in this release, written in Markdown. After launch they are converted to WordPress blocks and added to crawlwp.com/docs.

- Each file starts with front matter: title, slug, section, plan, excerpt, related articles, and the number of screenshots still missing.
- Screenshots are in each folder's `images/` (81 PNGs), taken on a test site running the merged release code. Screens that need Google, Analytics or AI data show sample data from a fictional bakery on the real CrawlWP screens.
- Three spots still need your live site. They are marked `<!-- SCREENSHOT (needs live site) -->` or `<!-- CHECK -->`:
  - the auth.crawlwp.com confirmation page (connect article);
  - Google's wording for the Analytics permission (connect article);
  - Google's Rich Results Test (rich results article).
- Every article was written from the code, illustrated, then fact-checked against both the code and its screenshots by a separate reviewer.
